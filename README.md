## ⚙️ Getting Started

### Requirements
- GCC compiler or another C compiler
- A code editor or terminal

### Compile and run

Compile an individual standard C source file:

```bash
gcc path/to/program.c -o program
./program
```

For example:

```bash
gcc Searching/linear-search/PR2EX1.C -o linear_search
./linear_search
```

> **Note:** Some older practicals use Turbo C-specific headers or functions such as `conio.h`, `clrscr()`, `getch()`, or the BGI `graphics.h` library. These may need a compatible environment or code changes to work with modern compilers.
