# C Programming Collection

A centralized collection of C programming practicals, data structures, algorithms, and computer-graphics exercises by **Prathamesh Sutar**.

## Repository contents

| Topic | Programs |
|---|---|
| Searching | Linear search, string search |
| Sorting | Bubble sort, selection sort |
| Recursion | String reversal, recursive multiplication, recursive linked-list display |
| Linked Lists | Linked-list operations, polynomial addition |
| Stacks | Array and linked/dynamic stack implementations |
| Queues | Linear queue, circular queue, linked-list queue |
| Computer Graphics | DDA line drawing, Bresenham line drawing |

## Folder structure

- `Searching/` — searching algorithms
- `Sorting/` — sorting algorithms
- `Recursion/` — recursion examples
- `Linked-Lists/` — linked-list programs and polynomial operations
- `Stacks/` — stack implementations
- `Queues/` — queue implementations
- `Computer-Graphics/` — line-drawing algorithms

## Compile and run

For standard C programs using GCC:

```bash
gcc path/to/program.c -o program
./program
```

Some older practicals use Turbo C-specific headers/functions such as `conio.h`, `clrscr()`, `getch()`, or the BGI `graphics.h` library. Those may require a compatible Turbo C/BGI environment or updates for a modern compiler.

## Important notes

- The source files were collected from the author's existing C-focused repositories.
- The original source code has been preserved; not every program has been tested or modernized.
- A few files may contain compilation or logic errors. Review and test them before relying on the output.
- C++ source files (`.cpp`) are intentionally excluded from this C collection.
- Original repositories remain unchanged.
